Pedagogical Philosophy SLIDE 02 / 12

"We Teach Communicative Language, Not Engineering Mechanics"

Aviation technician students already receive advanced technical systems and physics instruction in French. Our English lessons do not test memorization of hydraulic part numbers or ATA chapters.

1. Operational Confidence

Developing calm, clear, spoken English to describe incidents, hand over shifts, and explain technical disruptions.

2. De-Escalation & Stance

Practicing diplomatic language to resolve delays, negotiate apron access, and handle passenger disputes under EU261.

3. Global B2 Fluency

Simple, natural communication accessible to all students without theoretical linguistics or academic jargon.

Classroom Methodology SLIDE 04 / 12

The 120-Minute Task-Based Lesson Rhythm

Every 2-hour session follows a predictable, anxiety-reducing 4-phase pedagogical curve:

Phase 1 • 15m News Warm-Up

Current aviation headlines & rapid-fire vocabulary spot-check.

Phase 2 • 25m Language Clinic

Useful sentence patterns, linking words, and diplomatic negotiation phrases.

Phase 3 • 45m Live Simulation

Collaborative pair/trio role-play solving realistic incident dossiers.

Phase 4 • 15m Wrap-Up & Goals

Pronunciation audio drills + individual digital portfolio self-evaluation.

Includes a 20-minute teacher feedback & buffer window Turnkey Delivery

Institutional Governance SLIDE 08 / 12

Student Data Privacy (GDPR / PII Compliance)

French CNIL and EU GDPR regulations strictly forbid storing student personal data in cloud Git repositories or AI tools. Our dual-layer solution solves this completely:

1

100% Anonymous Git Codebase

All student rosters and FE evaluation rotas in Git use anonymous identifiers (GRPA001–GRPA010). Zero student names ever enter Git history or cloud logs.

2

Protected Local Mapping File

Real student names exist exclusively on the course director's local workstation in students.private.json, permanently blocked by .gitignore.

3

Automated Moodle Injection Pipeline

npm run package:moodle injects real names strictly into the final zip archive for ENAC eCampus upload, leaving local source code 100% anonymous.

Zero cloud PII exposure 100% GDPR Compliant

Operational Continuity SLIDE 10 / 12

Moodle Downtime Contingency Plan: The 3-Tier Fallback

Server outages must never disrupt live teaching. We guarantee 100% operational continuity:

TIER 1

Direct Local USB / Folder Launch (Primary Fallback)

Instructors launch index.html directly from a USB stick or classroom PC folder. Runs 100% offline with zero internet required.

TIER 2

Emergency Cloud Mirror (Live GitHub Pages)

An anonymous mirror is hosted at powerforcemotiondrive-pixel.github.io/GSEA_semester_1/. Students connect from phones or laptops in seconds.

TIER 3

1-Click Printable Handouts (Hardware Fallback)

Every lesson card features built-in print buttons to generate clean paper worksheets if student laptop batteries die.

Guaranteed Teaching Continuity Zero Lost Instruction Hours
