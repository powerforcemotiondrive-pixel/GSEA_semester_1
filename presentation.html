01

Curriculum Dual-Track: General vs. Technical

LV101E & LV121E

GSEA students take two distinct, complementary English courses each week. The platform unifies both syllabi into a single card deck while maintaining their distinct pedagogical identities:

General English (AG • LV101E) Fridays 08h00 – 10h00

Focuses on global B2 conversational agility, socio-environmental debates, green mobility, intercultural communication, and diplomatic negotiation skills.

Technical English (AT / AAS • LV121E) Wednesdays 13h15 – 15h15

Focuses on operational communication: aerodrome infrastructure, aircraft anatomy, ground turnaround workflows, standard phrases, and de-escalating operational disruptions.

Cardinal Principle: Language acquisition and operational fluency, not engineering theory.
02

Course Flow: The 120-Minute Lesson Arc

TBLT Methodology

Every 2-hour session follows a structured, confidence-building Task-Based Language Teaching (TBLT) curve. Lessons are turnkey: any teacher or substitute can step in with zero setup friction:

Phase 1 Warm-Up (15 min)

Current aviation news spot-check & rapid diagnostic vocabulary warm-up.

Phase 2 Language Focus (25 min)

Practical sentence patterns, connecting words, and polite negotiation formulas.

Phase 3 Simulation (45 min)

Collaborative pair/trio role-play based on authentic operational incident dossiers.

Phase 4 Wrap-Up (15 min)

Speech audio pronunciation drills + personal portfolio self-evaluation.

Leaves 20 minutes buffer for detailed individualized teacher feedback.

Continuous Assessment: Formative Evaluations

FE1 • FE2 • FE3

Traditional high-stakes written exams are replaced by continuous oral assessment across three formative evaluations spaced across the 15-week semester:

4 SLOTS

30-Minute Oral Tutorial Slots

Exactly four 30-minute evaluation slots per 2-hour session (13h15–15h15 for AT, 08h00–10h00 for AG) ensure 100% promotion capacity with zero scheduling overflow.

ROTAS

Dynamic Rotating Pairs & Trios

Students are systematically paired and grouped in alternating pairs and trios across FE1, FE2, and FE3, ensuring every student communicates with diverse partners.

RUBRICS

Transparent Published Criteria

Evaluation rubrics (Fluency, Operational Vocabulary, Interactive Communication, Task Completion) are openly visible inside the student deck to remove test anxiety.

Evaluation Dates: W48 (Nov), W03 (Jan), W08 (Feb) 100% Oral Assessment

Student Digital Portfolios

Self-Directed Learning

Every student maintains a dedicated digital learning log linked directly to classroom sessions, empowering reflective practice and tracking measurable linguistic growth:

1. Key Technical Vocabulary Learnt

Students log aviation terms and professional phrases covered during the session, writing operational definitions and realistic context examples.

2. Content & Operations Review

Students summarize aeronautical topics, ground procedures, or societal mobility debates explored during collaborative tasks.

3. Personal Communication Goals

Students identify specific pronunciation challenges, grammar patterns, or fluency hurdles to consolidate prior to the next formative evaluation.

One-click export: Students can print or save their portfolio logs as PDF for teacher review.

Moodle SCORM 1.2 & Offline Architecture

SCORM Certified

Packaged as a lightweight, certified SCORM 1.2 zip archive for ENAC eCampus / Moodle, combining deep LMS integration with zero reliance on external cloud services:

  • Automated Gradebook Tracking: Real-time SCORM handshake logs session completion (cmi.core.lesson_status) and quiz performance (cmi.core.score.raw) directly to Moodle.
  • Zero External CDNs: No Google Fonts, no external icon packs, no remote CSS frameworks. 100% of fonts, scripts, and vector assets are bundled locally.
  • Client-Side Speech API: Uses native browser Web Speech API for interactive UK/US audio drills, eliminating megabytes of heavy pre-recorded audio files.
  • Manifest Asset Verification: Automated build scripts verify all 44 bundled assets against imsmanifest.xml before producing the release zip.
Runs in any modern browser without plugins 6.95 MB Total Zip

Student Data Privacy & GDPR Compliance

100% PII Protected

European and French GDPR regulations strictly forbid storing student personal data in cloud code repositories (GitHub) or AI pair-programming systems. We solved this with a secure pseudonymization architecture:

1. Strict Codebase Pseudonymization

The Git codebase and public repositories strictly use anonymous student tokens (GRPA001–GRPA010). Zero real names ever enter Git history or cloud logs.

2. Protected Local Mapping File

Real student names are stored solely on the course director's local workstation in students.private.json, permanently blocked by .gitignore.

3. Dual Automated Packaging Pipeline

npm run package produces an anonymous package for Git/previews. npm run package:moodle injects real names strictly into the final zip archive for eCampus, leaving the working directory completely anonymous.

Fully compliant with French CNIL and EU GDPR data privacy mandates.

Eco-Conception

ENAC and French higher education require active integration of sustainable development (DD&RS). This platform demonstrates sustainability both technically and pedagogically:

Moodle Downtime Contingency Plan

Operational Continuity

Server outages and network interruptions can occur during academic terms. Our 3-tier contingency plan ensures zero instructional disruption if ENAC eCampus is temporarily offline:

TIER 1 • PRIMARY Direct Local USB / Folder Launch

Because the platform has zero external dependencies, instructors can launch index.html directly from a USB flash drive or desktop folder on classroom computers. Runs 100% offline in Chrome, Safari, Edge, or Firefox without any internet or web server.

TIER 2 • BACKUP Emergency Cloud GitHub Pages Mirror

A live, anonymous mirror is maintained continuously at powerforcemotiondrive-pixel.github.io/GSEA_semester_1/. Teachers can display the short URL or QR code on the board; students connect on laptops or smartphones in seconds.

TIER 3 • FALLBACK 1-Click Printable Handouts

Every lesson card features a built-in print action bar. If student devices run out of battery or hardware fails, teachers can print full activity sheets or save them as static PDF files on campus computers in seconds.

Continuity Guaranteed Zero Lost Teaching Hours
